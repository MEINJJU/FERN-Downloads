# FERN-Downloads

Hier findest du die öffentlichen FERN-Testversionen für Android TV und Fire TV.

## M4.1 Alpha

Öffne den [direkten APK-Link](https://github.com/MEINJJU/FERN-Downloads/releases/download/v0.4.1-alpha/FERN-M4.1-alpha.apk) in Downloader auf dem Fire TV. Bestätige anschließend die Installation. Die [Release-Seite](https://github.com/MEINJJU/FERN-Downloads/releases/tag/v0.4.1-alpha) enthält auch die SHA-256-Prüfsumme.

Falls FERN bereits installiert ist, installiere die APK als Update über die vorhandene App. M4.1 ist eine Debug-Testversion.
