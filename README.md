# FERN-Downloads

Öffentliche Testversionen für Android TV und Fire TV.

## M4.2 Alpha

Öffne den [direkten APK-Link](https://github.com/MEINJJU/FERN-Downloads/releases/download/v0.4.2-alpha/FERN-M4.2-alpha.apk) in Downloader. Bei einer vorhandenen FERN-Installation installierst du M4.2 als Update. Künftige Versionen kannst du unter **Einstellungen → Nach Updates suchen** abrufen.
